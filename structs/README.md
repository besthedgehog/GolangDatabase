# Абстрактный тип данных (АТД, Abstract Data Type, ADT)
Абстрактный тип данных – это описание что можно делать с данными, но не как это реализовано

АТД отвечает на вопросы:
* какие данные есть
* какие операции над ними разрешены
* какие гарантии они дают

Пример: 

```go
type Stack interface {
    Push(x int)
    Pop() (int, bool)
    IsEmpty() bool
}
```

# Массив Array

Массив представляет собой последовательно расположенный в памяти набор элементов фиксированной длины. Такое размещение позволяет за константное время О(1) обращаться к значению каждого элемента (получение или запись)
